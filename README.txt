# AMMA Primary School – Website

## Included
- `index.html`: Complete responsive single-page website.
- No external libraries or build tools required.

## Preview locally
Double-click `index.html` or open it in Chrome.

## Before publishing
1. Search in `index.html` for `91XXXXXXXXXX` and replace it with your WhatsApp number (country code + number, digits only).
2. Replace the email placeholder with your official email address.
3. Add your official class timings, course details, fees, and any real school/tuition credentials you want to display.
4. The website currently describes an online tutoring/learning support platform. Do not describe it as a recognised school or claim board affiliation unless that status is genuine.
5. Domain `ammaprimaryschool.online` is a suggested name only; check domain availability and register it before use.

## Publish
You can upload `index.html` to GitHub Pages, Netlify, or your hosting provider's public web root.
